Descriere Proiect Proiect de Deep Learning realizat în echipă, care utilizează o rețea neuronală convoluțională de tip ResNet50 pentru clasificarea automată a leziunilor cutante. Modelul a fost antrenat pentru a recunoaște diferite tipuri de afecțiuni dermatologice din imagini medicale.
